Pedagogy — 10-Year-Old Adaptation

0.1Build Before You Break

  • Concrete Visuals First: concepts ko real-world analogies aur visual utilities se link karein — Midnight Commander, Raspberry Pi GPIO, Wireshark visual stream.
  • "Ratna nahi, dekhna hai": command execute karne se pehle process tree aur data flow mentally visualize karwana.
  • Progressive Phasing: Phase 1 → Builder (L0–2), Phase 2 → Sysadmin (L3–11), Phase 3 → Auditor (L12–21), Phase 4 → Resource/Tool Master (L22–33).

0.2The "Red Line" — Ethics & Legal Guardrails

  • Golden Rule of Security: "Bina written permission ke kisi network ya system ko chhoona hacking nahi, digital trespassing/crime hai."
  • Strict Air-Gapped Sandbox: sab exercises 100% offline ya host-only local VMs mein. Is site ke terminal mein bhi Red Line enforced hai — external target try karo, block hoga (Level 32 demo).
  • Scope Definition: har lab ke shuru mein explicit "In-Scope" / "Out-of-Scope" checklist. Host OS ya home Wi-Fi router ko touch karna out-of-scope.
"Authorized environment. Always. No exceptions."
